# U.S. Career Academy - Website Project

A modern, production-ready, fully responsive website with stunning 3D effects for an online coaching institute focused on Business Analysis and Data Analysis.

## Project Structure

```
USCareerAcademy/
│
├── index.html
├── about.html
├── courses.html
├── faq.html
├── contact.html
├── enroll.html
│
├── assets/
│
├── css/
│     style.css
│     responsive.css
│     variables.css
│
├── images/
│
└── icons/
```

## Technology Stack

- **HTML5**: Semantic markup, accessibility features
- **CSS3**: Modern styling, CSS Grid, Flexbox, CSS Variables
- **NO JavaScript**: Pure HTML/CSS implementation
- **NO Frameworks**: No Bootstrap, Tailwind, React, or other libraries

## How to Use

1. Open `index.html` in any modern web browser
2. Navigate through all pages using the navigation menu
3. All pages are linked and work together
4. No server required - runs completely locally
